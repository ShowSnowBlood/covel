# 阵营声望 / Faction Reputation

一个可直接安装的 Covel 第三方插件。它在叙事回合结束后识别玩家对具名阵营造成的明确影响，维护 -100..100 的累计声望，并在右栏和消息区展示结果。

## 安装

1. 保持 ZIP 原样，不要解压后重新嵌套目录。
2. 在 Covel 的「设置 → 插件」中选择安装插件包。
3. 上传 `faction-reputation-1.0.0.zip` 并启用「阵营声望」。
4. 新建或继续一个至少启用了叙事引擎的会话。

ZIP 根目录直接包含 `package.json` 与 `PLUGIN.md`，符合 Covel 插件安装器格式。

## 行为

- 只追踪“阵营对玩家”的声望，不记录 NPC 个人好感或阵营之间的关系。
- 普通影响为 ±1..5，重要事件为 ±6..12，决定性事件最高 ±20。
- 分数累积并限制在 -100..100；档位由工具确定，模型不能直接指定。
- 同一阵营按名称去重；每轮最多更新 5 个阵营。
- 世界包可在插件命名空间 `reputation` 中预置 `{ id, name, score, notes? }`。
- 插件没有 API Key 或额外设置；使用宿主分配给插件 runtime 的 LLM slot。
