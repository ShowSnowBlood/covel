# Product

## Register

product

## Users

Covel serves AI RPG players who want to begin and continue a game without managing infrastructure, plus world and plugin authors who need predictable model behavior while testing their work. The hosted web experience should let a player use an existing FrostFox account and its entitled model channels. Desktop and self-hosted users retain local provider configuration and control.

## Product Purpose

Covel is a plugin-based AI RPG framework and playable application. Its interface keeps world selection, session play, plugin behavior, and model routing understandable without exposing kernel complexity. The first-party SaaS connection removes hosted users' need to paste provider secrets, while preserving explicit account state, model choice, billing ownership, and recovery paths.

## Brand Personality

Calm, creative, instrument-like. The interface should feel authored for sustained play and precise configuration, not like a generic SaaS control panel.

## Anti-references

Do not copy the FrostFox administration console into Covel, introduce a second component language, or turn account setup into a dashboard of decorative cards. Avoid gratuitous motion, opaque automatic model switching, and status treatments that rely on color alone.

## Design Principles

1. Keep play primary; reveal model-routing detail only where it changes a decision.
2. Make account, channel, and model state explicit, including who can fix a blocked state.
3. Preserve deployment boundaries: hosted FrostFox access must not weaken desktop or self-hosted local control.
4. Reuse Covel's themes, settings navigation, controls, terminology, and bilingual content.
5. Recover conservatively: transient failures must not silently discard credentials or user work.

## Accessibility & Inclusion

Target WCAG 2.2 AA for the account and model surfaces. Support complete keyboard operation, visible focus, readable contrast, reduced-motion preferences, screen-reader labels, and status cues that do not depend on color alone. Keep English and Simplified Chinese behaviorally equivalent.
